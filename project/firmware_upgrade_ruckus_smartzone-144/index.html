02 — Preparation

Preparation steps conducted before starting the upgrade to ensure smooth execution and minimize downtime risks.

Maintenance Window

Schedule maintenance window and inform stakeholders about potential downtime.

💾 Backup Configuration

Perform full configuration backup on both SmartZone 144 controllers (Active & Standby).

📦 Download Firmware

Download latest firmware image from Ruckus/CommScope support portal and verify checksum.

✅ Compatibility Check

Check compatibility matrix between firmware version, AP models, and active features.

🔑 License & Support

Ensure active license and support contract for access to latest firmware.

📞 Rollback Plan

Prepare rollback plan including previous firmware image and restore procedures.

⚠️ Important: Ensure downloaded firmware file matches SZ-144 model and recommended version by Ruckus/CommScope. Always verify MD5/SHA256 checksum before use.

04 — Upgrade Process

Firmware upgrade execution performed in stages on the HA cluster to minimize downtime. The Standby controller is upgraded first, followed by failover, then upgrading the previously Active controller.

🔴 Attention: During the upgrade process, APs will experience brief reconnection during controller failover. Ensure maintenance window has been communicated to users.

Step 1: Upload Firmware to SmartZone

Upload firmware image file to controller via GUI (Administration > Upgrade) or SCP/FTP. Wait until upload process completes 100%.

GUI Path: Administration → Upgrade → Upload Image
File: [ firmware_filename.img ]
Target: SZ-144 Cluster

Step 2: Upgrade Standby Controller (SZ-144 #2)

Initiate upgrade on the Standby node first. Controller will automatically reboot after upgrade completion. Wait until node comes back online and syncs with Active node.

Target: SZ-144 #2 (Standby) — [ x.x.x.x ]
Action: Upgrade → Reboot
Estimated Time: ± 20-40 minutes

Step 3: Verify Standby Controller Post-Upgrade

After SZ-144 #2 comes back online, verify new firmware version and ensure cluster sync is back to normal before proceeding.

Check: SZ-144 #2 firmware version → [ x.x.x.x ]
Check: Cluster sync status → Healthy
Check: AP connectivity → 6/6 Connected

Step 4: Failover – Switchover Active to Standby

Perform manual switchover/failover so that SZ-144 #2 (which has been upgraded) becomes Active, and SZ-144 #1 becomes Standby. APs will reconnect to the new controller.

Action: Administration → Cluster → Switchover
New Active: SZ-144 #2 [ x.x.x.x ]
New Standby: SZ-144 #1 [ x.x.x.x ]

Step 5: Upgrade Previously Active Controller (SZ-144 #1)

Now SZ-144 #1 is in Standby status. Perform firmware upgrade on this node. Controller will reboot and come back online with new firmware.

Target: SZ-144 #1 (now Standby) — [ x.x.x.x ]
Action: Upgrade → Reboot
Estimated Time: ± 20-40 minutes

Step 6: Verify Cluster & AP Auto-Upgrade

After both controllers are running new firmware, APs will automatically perform firmware upgrade in stages (rolling upgrade). Monitor the process until all 6 APs are completed.

Check: Both SZ firmware → [ x.x.x.x ] ✓
Check: Cluster HA → Healthy ✓
Check: AP Auto-Upgrade → 6/6 Complete
