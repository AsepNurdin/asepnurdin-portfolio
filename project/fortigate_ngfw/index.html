01 — Background & Objectives

Background

Traditional firewalls are no longer sufficient against modern cyber threats. Next-Generation Firewall (NGFW) provides comprehensive security with application awareness, integrated intrusion prevention, and cloud-delivered threat intelligence.

  • ▹ Rising sophisticated attacks targeting network perimeter
  • ▹ Need for application-level visibility and control
  • ▹ Compliance requirements (PCI-DSS, ISO 27001)
  • ▹ Consolidation of multiple security functions

Implementation Objectives

Network Segmentation

Implement zone-based security with proper network segmentation (DMZ, LAN, WAN).

Application Control

Deploy application-aware firewall policies to control bandwidth and access.

Threat Prevention

Enable IPS, Antivirus, Web Filtering, and Application Control profiles.

SSL Inspection

Implement SSL/TLS deep inspection for encrypted traffic analysis.

Logging & Reporting

Configure comprehensive logging and real-time threat monitoring.

05 — UTM (Unified Threat Management) Profiles

Security Profiles Configuration

🛡️ IPS Profile: "default-strict"

Intrusion Prevention System configured with strict signature set to detect and block known exploits, malware, and attack patterns.

  • Critical & High severity signatures enabled
  • Block mode for known exploits
  • Protocol anomaly detection
  • DoS/DDoS protection enabled

🦠 Antivirus Profile: "av-profile-full"

Real-time antivirus scanning using FortiGuard Labs database with heuristic analysis for unknown threats.

  • Scan compressed files (up to 3 levels)
  • Scan archives (ZIP, RAR, 7Z)
  • Block infected files automatically
  • FortiGuard real-time updates

Web Filtering Profile: "web-filter-corporate"

Category-based URL filtering to block malicious and inappropriate websites.

  • Block: Malware, Phishing, Adult Content, Gambling
  • Warn: Social Media, Streaming
  • Allow: Business, Education, Technology
  • Safe Search enforcement (Google, Bing)

Application Control: "app-control-standard"

Identify and control applications regardless of port or protocol using deep packet inspection.

  • Block: P2P, Torrent, Proxy Avoidance
  • Limit: Video Streaming (YouTube, Netflix)
  • Allow: Business Apps (Office 365, Salesforce)
  • Monitor: Social Media usage

SSL Inspection: "deep-inspection"

Deep SSL/TLS inspection to detect threats hidden in encrypted traffic.

  • Decrypt and inspect HTTPS traffic
  • Certificate validation
  • Block self-signed certificates
  • Exclude: Banking, Healthcare (privacy)

06 — Implementation Steps

Phase 1: Initial Setup

1. Factory Reset & Firmware Update

# Backup default config execute backup config flash factory-default.cfg # Update to latest firmware config system firmware set path "https://support.fortinet.com" end execute restore image https://.../FortiGate-60F-v7.2.x.out

2. Interface Configuration

config system interface edit "port1" set mode static set ip x.x.x.x 255.255.255.240 set allowaccess https ping set description "WAN" next edit "port2" set mode static set ip 10.10.10.1 255.255.255.0 set allowaccess https ping set description "LAN" next edit "port3" set mode static set ip 192.168.1.1 255.255.255.0 set description "DMZ" next end

Phase 2: Security Policy Creation

3. Create Address Objects

config firewall address edit "LAN_Subnet" set subnet 10.10.10.0 255.255.255.0 next edit "DMZ_Subnet" set subnet 192.168.1.0 255.255.255.0 next edit "Web_Server" set subnet 192.168.1.10 255.255.255.255 next end

4. Create Security Policies

config firewall policy edit 1 set name "LAN_TO_INTERNET" set srcintf "port2" set dstintf "port1" set srcaddr "LAN_Subnet" set dstaddr "all" set action accept set schedule "always" set service "HTTP" "HTTPS" "DNS" set nat enable set utm-status enable set ssl-ssh-profile "deep-inspection" set av-profile "av-profile-full" set webfilter-profile "web-filter-corporate" set application-list "app-control-standard" set ips-sensor "default-strict" set logtraffic all next end

Phase 3: Testing & Validation

5. Policy Testing

  • Verify LAN users can access internet
  • Test web filtering (blocked categories)
  • Validate IPS detection (EICAR test)
  • Confirm NAT translation working
  • Check DMZ server accessibility
